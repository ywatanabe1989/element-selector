✨ Features

🎨 Visual Inspector

See all elements with color-coded overlays based on nesting depth

📋 AI-Ready Debug Info

Click any element to copy comprehensive debug data formatted for AI assistants

📸 Full Page Capture

Export entire page structure with one keyboard shortcut

🔲 Rectangle Selection

Select multiple elements at once with click-and-drag

⌨️ Keyboard Shortcuts

Alt + I Toggle inspector overlay
Alt + C Copy full page structure
Ctrl + Alt + I Start rectangle selection mode
Esc Cancel selection mode

🛠️ Alternative Installation

For Developers

Add to your HTML:

<script src="element-inspector.js"></script>

Via NPM (Coming Soon)

npm install element-inspector

Browser Console

Paste this in any webpage's console:

var s=document.createElement('script'); s.src='https://YOUR-GITHUB-USERNAME.github.io/element-inspector/element-inspector.js'; document.head.appendChild(s);
